# FIX-5.62.273 进出洞南线普通跳崖、桧皮镇与桐树林回归

参考：NPC-5.62.243 / ILEX-5.62.217；Gold 源图及碰撞。此为开发候选，不是手机实测结果。

1. 成熟源中桐树林已验收的图块对/共用执行器与两次模拟输入保持不变。Route33 与桧皮镇仍按原有7/10个有向 Gold 坐标跳跃，不把第三格墙当成禁止合法跳跃的依据。
2. 当前主项目额外的南线空间碰撞网关在跳跃标志 wd736.6 未结束时会绕过普通树林阻挡。新函数 `JohtoSouthHopLandingGuard` 仅在实际坐标已达到一次合法跳崖的 **第二格落点** 时拒绝新一轮跳跃移动；不缩短模拟队列、不改动画、只限制 33号路、桧皮镇和桐树林。仍需 ROM 实机验证第三格及动画标志时序。
3. 原迁移工程的新南部门房使用独立块集，和成熟 NPC 的压缩 `JOHTO_GATE` 图块映射不同。两座门房现回用成熟图块集、成熟 `.mature.blk` 和黑色边框 `$0d`；原始 Gold `.runtime.blk` 不变，独立审计确保原始资源与成熟版运行资源各自正确。
4. 重点复验：Route33 左跳及下跳全部7条、桧皮镇标牌 `(10,6,DOWN)` 等10条、桐树林10条方向，按住或松开方向键/B，跳下后向树走应阻挡，不得第三步越界、穿树或死机。两座门房东西／南北双向往返、角落显示及黑色边界；不扩大未开放门口。
5. 编译链接仍由项目所有者执行。旧 MAP ROM0 余26字节不满足项目64字节安全门槛，不能用旧 MAP 宣称本轮可链接。ROM0 入口有少量新增，须检查新 MAP；无 ROM 链接验收前不得做清理提交。
