# BATTLE-5.62.204 — 可选战斗测试构建（长期有效）

> 本文记录**当前已保留的测试框架**，不是旧 T01～T08 补丁操作手册。正式提交以已确认的 `BATTLE-5.62.203` / HEAD `71d78a1a4a80949e4ec903212991a4726ed24f9c` 为基线。生产与测试编译共享正式战斗算法，但测试 ROM 额外注入受控输入；不可将测试结果解释为自然 RNG/存档流程的全面验证。

## 构建与隔离

| 本地命令 | 产物 | 版本显示 | 专用测试设施 |
|---|---|---|---|
| `make red` / `make blue` | `patches/rppred.gbc` / `patches/rppblue.gbc` | `TEXT-5.62.205` | **不编入**测试 NPC、Hook、专用状态别名、测试 helper |
| `make test-red` / `make test-blue` | `patches/rppredtest.gbc` / `patches/rppbluetest.gbc` | `B-5.62.204-T09` | 启用测试 NPC、三个测试组和受控战斗输入 |

正常功能版本号升级不自动同步战斗测试 ROM 专用标签；当前测试标签仍保留 `B-5.62.204-T09`，只有测试设施自己改版时才另行调整。

只有显式传递 `-D BATTLE_TEST_BUILD` 才编入测试设施；四种目标使用各自的 `.o`，默认 `make`/`make red`/`make blue` 不包含它们。`test-red` / `test-blue` 必须与正式 ROM 使用**不同的 SAV 路径或独立模拟器存档目录**。测试组会覆盖**测试存档**的当前队伍，不会自动恢复，切勿共用主存档。

## 地图入口与菜单

- 两种构建都保留玉虹大厦 1F 原老太太及三个导师的原始功能和文本。
- **仅测试 ROM** 增加 `SPRITE_POKEY` 测试 NPC。坐标为**用户手工定稿**的 `($00,$0A)`，朝左，保留原位，不要按过时的 `(5,5)` 恢复。
- 与 Pokey 对话，在提示中选 YES，显示三选一菜单；上下选择，A 启动，B 取消。第一层选择 NO／B、第二层 B 都必须不改队伍，退出后对话框应自然消失。
- 在 `EndOfBattle` 后清零本轮测试激活状态；该清零**不**会恢复存档中的测试队伍。

## 实现边界与防回归

- 正式算法不因 `BATTLE_TEST_BUILD` 改动：`AttackSubstitute`、正常命中函数、真正的伤害计算继续执行；Hook 只为指定测试准备输入。正式 ROM 的对应调用均被编译期条件完全排除。
- 仅在地图入口触发指定野战后测试状态才激活；临时标记使用 `$D7C7/$D7C8` 两个旧的未用道馆索引字节，仅供测试 ROM；不新增 SRAM 字段或改动 WRAM 地址布局。
- 多段连续击不等于多个回合：只在完整回合边界推进阶段。远调用不要用寄存器 A 返回击数；当前测试 helper 用 E 返回并由调用者恢复相关寄存器。
- 选择菜单 A/B 两条退出路径必须严格保持栈平衡；`PrintText` 与菜单退出后，由 `DisableWaitingAfterTextDisplay` 关闭外层文字框，避免旧提示残留。
- 旧版画框越界、A/B 栈损坏、残留文本、错误 `SPRITE_YOUNGSTER`、211T 的 15 击错误属于**历史测试夹具问题**；修复根因和边界记录见 `RPP_DEVELOPMENT_PITFALLS.md`，不要回滚旧实现。
