# 百变怪「变身者」入场自动变身（IMP-5.62.207）

## 功能边界

本功能仅为 `DITTO` 实现固定的入场自动变身效果，不建立通用 Ability 数据系统。正式 ROM 版本为 `IMP-5.62.207`。

- 玩家或敌方百变怪首发、主动换入、昏厥补位时，均在实际登场节点自动尝试变身。
- 双方同时昏厥时，玩家百变怪的触发会等待新敌方宝可梦完成装载，避免复制 HP 为 0 的旧目标。一次性挂起标志会在玩家新入场时重置，并在敌方新目标到位后消费。
- 成功复用项目的 `TransformEffect_` 判定与战斗临时数据复制，包括物种／运行时形态、外观、属性、相关能力变化、招式与扩展招式身份。临时招式 PP 按现有 Transform 规则设置；不复制目标当前／最大 HP，不永久改写 Party 四招或 SRAM。
- 保留项目现有失败判定：目标处于 Fly/Dig 半无敌状态、施术者已变身、双方当前物种及运行时形态均相同。替身不额外作为失败条件；不擅自加入后世代规则。
- 自动失败保持原状，静默返回，不额外消耗行动或 Transform PP；手动 Transform 仍走原执行路径。
- Battle Animation 开启时播放项目原生 Transform 动画，关闭时直接重绘。自动效果保护先前动画 ID/type，不更改已选择招式。
- 正常训练师换人时序不被正式版改写；自动变身本身不额外消耗一回合行动。

## 主要源码入口

- `engine/battle/imposter.asm`：双方上场钩子、双倒挂起状态、自动动画。
- `engine/battle/moveEffects/transform_effect.asm`：`ImposterTransformEffect_` 与现有 `TransformEffect_` 共用判定／复制。
- `engine/battle/core.asm`：玩家与敌方真实登场入口。
- `main.asm`：将变身相关逻辑放入可浮动 ROMX，避免继续挤占已接近满载的固定 Bank。
- `wram.asm`：一个非持久临时标志；不新增 SRAM 字段。
