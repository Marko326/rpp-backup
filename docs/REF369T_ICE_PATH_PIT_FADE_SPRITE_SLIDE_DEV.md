## 基线与边界

以用户已应用的 REF-369S@ 为增量前置状态；正式基线仍为已在累计补丁中可重建的 REF-368 HEAD `935b3fa738dce42f22768e94c92c920bb5b86d89`，不擅自更换 Git HEAD。本阶段不修改两槽烟尘、推石/震动音效、存档位或关东。

## 三处修复

1. **普通洞穴进出方式**：此前 B1F #3–#6 落洞使用烧焦塔白屏退场；现在继续复用已存在的坠落角色动作，但退场改调用全项目统一的 `PlayMapChangeSound`（洞穴黑色过渡和 LCD-on 安全地图装载），进入 B2F 则使用既有的 `GBFadeInFromBlack`。烧焦塔继续使用原来的白屏效果。未另写独立过渡例程。
2. **B2F 未落石头首次显示**：从 B1F 掉洞进入 B2F Mahogany 时，在 `JohtoEnterMapAnimationDispatcher` 的任何入场淡入前，先执行原有的迁移初始化，再执行原有 B2F 落石同步。未落的石头同时令 C1x2 当前帧与 C2x4/5 坐标为 `$ff`；保留 REF-369E 的非零精灵图片 ID 以免保存后图块花屏。地图脚本仍做原来的同步以覆盖普通地图加载。
3. **冰面加速**：Gold 原版 `STEP_ICE` 从 `.SlideStep` 映射到 `fast_slide_step`（即 `STEP_BIKE`），而工程的 60 FPS 自动滑冰先前仅有 16 像素／16 帧的正常步行速度。只在已激活的自动滑冰方向合成 `B_BUTTON`，复用 `home/overworld.asm` 已有的 `DoBikeSpeedup`，让滑行趋近 16 像素／8 帧；不修改步长、普通地面跑步、NPC、Warp、碰撞、踏入冰面的第一步和骑车专用分支。

## 设备验收

1. 从四个 B1F PIT 分别落到 B2F，确认过渡黑色且与普通洞穴换层风格一致，原有下落动作仍然执行；无二次传送。
2. 未落下任何石头时进入 B2F，注意入场**第一帧**不能闪出石头；部分与全部落石状态下再测。保存、读档及 START 正常。
3. 冰面上持续自动滑行时速度应明显快于原本 16 帧/格，Gold 原版以 STEP_BIKE 步长为准；普通地面速度、B 加速、撞墙停下、楼梯与普通洞口不受影响。
