> **历史说明：** 此文保留 200 开发阶段的设计和当时“待测”矩阵，不再是最新验收状态／规则源。最终规则、真实用户反馈和第二轮待办，统一以 [`BATTLE_200_FINAL_RULES_AND_ROUND2.md`](BATTLE_200_FINAL_RULES_AND_ROUND2.md) 为准。

## 输入与边界

- 项目来源：用户 2026-10-21 上传的干净 `MOVE-5.62.199` ZIP，导出 HEAD `66c9b058aa4558ec9d0712cd7349ee877f8996f0`。
- 本版只修改普通战斗受击记录/Counter、Stat Modifier 引起的烧伤/麻痹重新应用以及游戏版本。**保留** Spark `DYNAMIC` 元数据、图鉴图块、能力比较规则、伤害通路、动画、PP 和附加效果。
- 不加入 pureRGB 幽灵属性基础能力判类，不恢复 199D/199E 的长期低字节缓存，不更改任何 SRAM 保存结构。

## Counter 新语义

1. 每次双方完成命令选择、进入出招排序之前，使双方本回合受击记录无效；防止跨回合、换人或旧光标污染。
2. 真实 HP 扣除并将伤害封顶至剩余 HP 后，从实际伤害应用入口记一笔：受击方、最终扣除 HP、攻击方当时物理/特殊类别。
3. 只有*对方*、有非零基础威力、非 Counter 的真正物理招式命中本体且扣除 HP 后，标记可 Counter。普通物理和当次 Physical Spark 共用此规则。其他命中清空有效标志。
4. Counter 只取自己本回合最近有效的受击记录计算 2 倍伤害（最大 65535），然后仍走原命中率检查及类型作用流程；不依赖对手光标和自己的攻击/特殊数值。
5. 替身截断在真实 HP 扣除之前，不生成受击事件；自伤、反伤路径依靠攻击者一侧判别排除。多段攻击每段发生真实 HP 扣除时可以刷新记录。

注意：这是以“当前回合实际受到的可反击伤害”为目标的**公共 Counter 语义调整**，与原 Gen1 Counter 的若干历史缺陷行为不同。部分固定伤害招式的基础威力为零，仍沿用旧的不可反击约束。实机验收前不得声称全面兼容官方所有世代 Counter 规则。

## 烧伤/麻痹

- 进入战斗或新烧伤／麻痹时，沿用原有状态施加函数。
- 在 `StatModifierUpEffect`／`StatModifierDownEffect` 修改真实 Attack 或 Speed 时，只重施加与该项对应的烧伤或麻痹折半。注意升能力作用于出招者，降能力作用于对方：升能力调用前暂时反转 `H_WHOSETURN`，调用后原样恢复。
- 防御／特殊／命中／闪避升降不应使已经折半的 Attack/Speed 再被折半；自我特殊降低也不会重新对 Attack 折半。
- 这项修复同时影响所有正常物理招式及 Speed 顺序，不是 Dynamic 特有规则。

## 最小测试矩阵（全部待用户实机验证）

| 场景 | 期望 |
|---|---|
| 敌方物理 Spark 命中己方，再使用 Counter | 成功反击，约为实际 HP 损失的两倍 |
| 玩家物理 Spark 命中敌方，敌方 Counter | 同上；不要按 Counter 使用者 Attack/Special 判类 |
| 特殊 Spark 命中，或普通特殊招式命中 | Counter 失败 |
| 普通物理招式命中 | Counter 成功且伤害准确 |
| 使用 Counter 时对方尚未造成伤害 | Counter 失败，不继承上回合／上只宝可梦的记录 |
| 上次伤害来自自伤/反伤、替身、被免疫或没有 HP 损失 | Counter 失败 |
| 伤害超过当前 HP，或多段伤害 | 反击基于实际扣除 HP；不得读取过期全局伤害值 |
| Metronome/Mirror Move 派生 Spark、扩展序号 13 | 不与普通 Spark 低字节身份混淆 |
| 先烧伤，后下降防御/提升特殊 | Attack 不再次减半，所有物理技能伤害正常 |
| 烧伤后上升/下降 Attack | 重建后只对新的 Attack 折半一次 |
| 麻痹后变动与 Speed 无关的能力 | Speed 不再次减半 |
| 麻痹后上升/下降 Speed | 重建后只减半一次 |
| Spark 光标第二/四槽快速切换 | 没有光标跳选、花屏或分类延迟 |
| Red / Hard 双模式链接与 ROM 运行 | 无 Bank 溢出、断链、菜单/战斗回归 |
