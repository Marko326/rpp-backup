# FIX-5.62.290｜35号路北连接的右侧3列预览

## 复现与历史

用户手机 `GBPocket-20261031-175253.png` 与 `62.289.mp4` 显示：35号路走到36号路南接缝时，视野右上角仍有外围树林。36号路东侧到桔梗市的用户实测正常。
旧成熟参考 `NPC-5.62.243/docs/JOHTO_CONNECTION_VISUAL_223_CLOSEOUT.md` 把窄图北接宽图的显示列数作为专用连接审计闸门：**Route35→Route36 应显示13列，而不能只显示10列**。
旧工具源代码未随当前交接包保留，本轮在现有项目的 `tools/johto_route36_seam_audit_289.py` 中补齐强制检查，并保留对Gold地图、碰撞、准确出口的既有核验。

## 实际改动与边界证明

- Route35 宽10，地图WRAM含左右各3列边框，总缓冲宽16。NORTH可视条带从目标列3开始，复制13列结束在列15；14列会超出16列缓冲。
- 源图Route36宽30、高9；取最后3行（行6/7/8）各13列。源最后访问索引 8×30+12=252，小于270字节图长。
- 北向真实可走出口仍只有 x17，Route36北接37号路继续关闭，右向桔梗接缝不改。
- 运行时 `LoadNorthSouthConnectionsTileMap` 逐行使用Header提供的长度，复制3行；改动只有Header宽度字节，不增加ROM0逻辑或新资源。

## 必测

离线：综合Gold审计、单元测试、故障注入、ASM标签。实机：从35进入36沿右边视野滚屏查看右上角，随后36返回35；再检查36东进桔梗以及骑行。新链接MAP须确认ROM0>=64B。测试版本保持TEST-231。
