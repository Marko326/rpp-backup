# FIX-5.62.269 南线交接回归修复记录

## 来源

当前 MAP-5.62.268 候选 vs 已验收的 NPC-5.62.243（包含 ILEX-5.62.216/.217）与 Gold `pokegold-master`。这是开发修复候选，不是 ROM 实测完成声明。

## 确定修复

1. 33号道路左边缘：外层 `JohtoPilotIsClosedOutdoorEdge` 已允许 `(x=0,y=14/15,LEFT)`，但内层 `JohtoRoute33StepPolicy` 执行 `dec b` 后溢出成 `$ff`，触发 `.bounds` 阻挡。只对这两个 Gold 坐标直接返回 `E=0`，不扩大其它地图出口。
2. 桐树林：使用成熟分支 `.217` 的森林艺术源/区块集，共46块；在仍然不可更改的 Gold 405字节源图上，只将偏移26、27、112、176、177、178处改为40、41、42、43、40、44；对应两套地图字节是有意不同的。引用 `$05→$40/$41/$42` 图块配对，保持原始 `.foundMatch` 两步模拟和动作，不设计新的跳跃执行器。Cut `$0f→$2d` 是另一个独立区块，碰撞跟随活图块状态。
3. 森林配色：CAVE 背景组以及原分支夜间对象色；不把 Cut 动画染成白天绿色。
4. 城都屋顶：原版 `gfx/tilesets/roofs/{new_bark,violet,azalea,goldenrod}.png` 拷为可跟踪 PNG 源；RGB5 参考成熟 `.216` 与 Gold `roofs.pal`。同时在 `LoadTilesetTilePatternData` 后和无缝连接 `LoadMapHeader` 后替换九个 tile，确保走路跨城不会遗留上一组屋顶图案。
