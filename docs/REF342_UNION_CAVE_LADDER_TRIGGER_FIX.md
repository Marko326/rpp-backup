# REF-342｜联合洞穴楼梯触发语义修复

## 用户现象
B1F 的角落楼梯在人物已经站上楼梯后，撞墙或继续按方向仍可能触发换层；这与 Gold 原版楼梯行为不一致。

## Gold 原版语义
Gold `CAVE` 碰撞明确区分两类 Warp：

- `LADDER`：从相邻格走入楼梯格的那一步立即触发；人物已经站在楼梯格时，撞墙/按其它方向不能再次触发。
- `WARP_CARPET_DOWN`：人物可站在格上，只有指定的向下输入才触发。

联合洞穴内部楼梯：1F `(5,19)/(3,33)`、B1F `(7,19)/(3,33)/(17,31)`、B2F `(5,3)` 全部是 `LADDER`。1F `(17,3)/(17,31)` 是 `WARP_CARPET_DOWN`；B1F `(3,3)/(3,11)` 也是方向地毯，但遗迹路线当前继续关闭。

## 修复
`JohtoPilotGateDoorWarpMatched` 在精确 Warp 坐标匹配后按 Gold 类型分流：LADDER 返回立即 STEP_ON 模式，方向地毯只武装站立状态。`JohtoPilotGateCollisionExitAllowed` 对 B1F/B2F 楼梯明确返回禁止碰撞 Warp，避免站在楼梯上撞角落墙时再次换层。1F 两个真实洞口仍保持 DOWN-only。

不改地图块、Warp 坐标、目标 Warp ID、同 Tileset 落点修复、Surf、碰撞热修、边框或调色。

## 实机验收
1. 从普通地面走进 B1F 三个内部楼梯，应在踏上楼梯的那一步立即换层。
2. 从目标层返回后人物落在楼梯格；此时按 A、朝墙方向或其它不会离开楼梯的输入，不应再次换层。
3. 正常走离楼梯后再走回，才再次触发。
4. B1F `(3,3)/(3,11)` 遗迹方向仍不得触发。
