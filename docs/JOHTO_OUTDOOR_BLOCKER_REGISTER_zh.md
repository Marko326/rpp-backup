## 今后每接一张室外地图，必须执行的检查（不得省略）

1. **接图前**：列出新图与每张相邻已接入地图的方向、宽度/高度、边界通道和原版 Gold `*.blk` 来源；如共享布局，按 `data/maps/blocks.asm` 真正引用定位。
2. **逐项登记**：比较 Gold 与 RPP 的 `.blk`、地图事件对象、Warp、入口封路 NPC、地图头连接以及 `home/overworld.asm` 的代码边界；每个差异要有 `id / 分类 / 位置 / 原值 / 现值 / 设置原因 / 解除条件 / 状态 / 验证`。
3. **先确认，后修改**：只处理状态为 `CONFIRMED_REMOVE` 且解除条件已满足的定点项；`PRESERVE`、`UNKNOWN`、仍依赖未做地图/室内的项不可一起删。
4. **最小更改**：只改对应 `.blk` 的特定坐标或对应的代码分支；禁止“全图替换树块”，禁止直接用 Gold 整张地图覆盖已经改造的 RPP 跳崖区块。
5. **检查可达性**：静态核对入口前后一格的碰撞、连通方向、连接高度和回退路径；在游戏内验证双向通行、边缘安全、路牌、跳崖、Continue、渡轮和关都回归。
6. **提交前收口**：更新 CSV 中 `status / verification` 和本 Markdown；`TODO.md` 与 `RPP_DEVELOPMENT_PITFALLS.md` 写结论，补丁只纳入必要内容。未经运行确认，不把静态结果标为“玩家已通过”。
