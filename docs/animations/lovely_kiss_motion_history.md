# Lovely Kiss：运动方案与版本对应（交付定稿）

本项目采用 3 条真实连续历史提交，分别实现九锚点逐帧轨迹、节奏浅弧与远近双波浪。记录此文件是为了让以后优化时不覆盖选定的设计。

| 主线版本 | 源提交（原版本） | 功能范围 |
| --- | --- | --- |
| `ANIM-5.62.75` | `b145d3e5` (`LK-5.62.58`) | 9个X原锚点与Lovely Kiss独立6帧OAM位移 |
| `ANIM-5.62.76` | `6cfbb95a` (`LK-5.62.61`) | 每帧(Y,X)查表变速，远侧波峰3px浅弧 |
| **`ANIM-5.62.77`** | **`d8ee44ec` (`LK-5.62.62`)** | **每关键点独立Y偏移；近波35px、远波26px** |

## 定版行为

- 仅在普通 Lovely Kiss 调用专用浮动 ROMX helper；原共用 Subanimation `$12` 和其他招式仍按原路径运行。
- 仍使用9个原X锚点、8段各7 VBlank动作，按段6对 `(Y,X)` 有符号位移；下一帧块提供余下的锚点重绘，偏移只作用于OAM中的Y字节。
- Y偏移依次是 `0,0,-3,-1,-2,0,+4,+4,+1`；调整后的Y关键点是 `88,66,53,63,70,62,44,44,49`。第一波升高 `88-53=35px`，第二波 `70-44=26px`；这是锚点几何高度，不是对屏幕观感的像素级录像测量。
- 保留第二波峰的短浅弧、双向镜像、音效调用与第九帧段离场 `(Y,X)=(+1,+3)`；不改技能伤害、PP或公共 FrameBlock。
- 源提交 `d8ee44ec` 记载，使用者曾对照 `62LOVE.mp4` 选择了最终视觉方案。该记录可解释设计取舍，但本次没有额外编译ROM或重新采集运行视频。

## 兼容性与审查

实际运行指令及两组数据表与源提交逐项相同；本轮同时核对 `SmoothBattleAnimDelayFrames`、`wSubAnimTransform`、`wFBDestAddr`、OAM数组步长及 `main.asm` 的浮动ROMX引入。只修改专用动画及本次版本/TODO/设计文档，既有高音、伏特攻击、飞天、冲浪及队伍图标文件不变。

后续反馈如需调节波幅，以 `ANIM-5.62.77` 为新独立补丁的起点，勿再回退到原始55～57匀速、停顿冲刺方案。
