# Draining Kiss：正式方案与历史对应

基线：`ANIM-5.62.77`，本次 `ANIM-5.62.78` 独立移植源提交 `d825f292`（原分支 `LK-5.62.62 → DK-5.62.66`）。本文件记录**实现设计**，不将源码静态核对伪装成新录制的游戏画面。

## 当前实现

- 在 `DrainingKissExtAnimData` 中使用动作 `$06,$8D,$39`：`Subanimation39` 含七个心形锚点，其后的 `$21`、`$22` 分别是现有 Absorb 的收缩与回程；不复制、不改动这两个通用吸收阶段。
- 进入动画时切到 `EXT_PALETTE_MODE_MOVE_TYPE`（Draining Kiss 属 Fairy），最后通过 `SE_RESET_SCREEN_PALETTE` 和 `EXT_PALETTE_MODE_FIXED` 显式恢复。
- 只在 **脚本加载状态 `1` + 动画身份 `LOVELY_KISS` + 子动画 `$39`** 的路径调用七锚点 OAM 曲线；普通 Lovely Kiss 使用非脚本的 `$12` 九锚点路径，其他共享子动画保持原路径。
- 两方向使用独立 Y/X 锚点偏移与末三段 `(Y,X)` 每帧位移；其中第七个锚点结束只停留两帧，随后直接交给原始 Absorb 收缩，未做额外最终坐标瞬移。
- 为兼顾两方向不同的视觉形心，X/Y 位移在 OAM 表现层调整，不改共享 FrameBlock 数据、技能伤害、吸收量和 PP。
